## 一句话版本

本站没有注册和登录，我不收集你的姓名、邮箱这类身份信息。有一个[留言板](/guestbook/)，署名可以不填，留言我看过才公开。为了知道文章有没有人看、读者从哪里来，本站用了**一套第三方访问统计**（Cloudflare Web Analytics，不用 Cookie），外加**本站自己的计数**（只记日期、大致地点和打开的是哪篇文章，不存 IP，不用 Cookie）。本站不设置任何跟踪 Cookie。下面说明它们记什么、存什么。

## 访问统计

这套统计只在正式域名 `zhuoqidev.com` 上加载，本地预览和测试构建不加载。它记录的是常见的访问数据：访问的网址（包括站内搜索时网址里的 `?q=` 搜索词）、来源页面、浏览器和设备类型、大致地区、访问时间，以及页面加载快慢的性能数据。

| 服务 | 用途 | 是否设置 Cookie | 隐私政策 |
| --- | --- | --- | --- |
| Cloudflare Web Analytics | 页面性能和访问量 | 否，不用 Cookie 也不用本地存储 | [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/) |

这些数据由 Cloudflare 收集和保存，我只在它的后台看汇总报表（如每篇文章的阅读量、来源渠道），不会把数据和具体的人对应起来，也不会出售或转交给任何人。

**不想被统计**：用广告 / 跟踪拦截插件（如 uBlock Origin）屏蔽它的脚本即可，屏蔽后本站所有内容照常可用。它不在你的浏览器里存任何东西，所以没有 Cookie 需要清。

## 本站自己的计数

除了上面这套，本站还自己数两样东西，数据存在 Cloudflare 的数据库（D1）里。按国家、省份和爬虫汇总后的数字公开在[访客地图](/visitors/)上，谁都能看；城市一级的明细只有我能看；每篇文章的数字不公开，只用来排「最近热门」的先后：

- **真人浏览**：每打开一页，页面会发一个请求（不带 Cookie），用来数各地的浏览数，以及每篇文章被多少人打开过。**IP 本身不保存**，两条线的做法不同：
  - 海外线（Cloudflare）：请求发到 `api.zhuoqidev.com`，带上当前页面的路径。服务器只记三样：日期；Cloudflare 当时根据你的 IP 查出的国家、省份和城市；如果这一页是文章，记下是哪篇（只记文章名，如 `verify-llm-relay-api`，不记完整网址，中英文版算同一篇）。为了数「今天有几位访客」「这篇文章今天有几位读者」，服务器把 IP 和浏览器标识（User-Agent）加上一个每天随机生成的盐做成哈希，第二天盐和哈希一起删掉，之后谁也没法把它还原成 IP。
  - 国内线（阿里云 CDN）：页面向本站自己的域名取一个 1 像素的图片 `/hit.gif`，这次请求和其它请求一样记在阿里云 CDN 的访问日志里，日志里这次请求的来源页（Referer）就是你正在看的那一页。每天读一次前一天的日志，用开源的 ip2region 离线库把 IP 查成国家、省份和城市，按「同一 IP 加同一浏览器标识算一位访客」数人数——这个 IP 和浏览器当天还得取过页面或页面里的文件才算，只取了这张图、别的什么都没取的多是自动程序，不计入；存进数据库的只有每个地方、每篇文章（同样只记文章名）的浏览数和访客数。读日志的程序跑在 GitHub Actions 上，用完即弃，IP 不离开它。
- **爬虫访问**：按请求里的 User-Agent 认出是哪家的爬虫（如 Googlebot、百度、ClaudeBot），每天只记「哪个爬虫来了几次」。海外线由 Cloudflare 上的服务器实时计数；国内线每天读一次阿里云 CDN 的访问日志来数，读完只留这个次数。

上面的第三方统计被拦截时，本站自己的计数照常；这个请求（或 1 像素图片）被拦截也不影响任何功能。

**每篇文章的计数用来做什么**：文章列表顶上和每篇文章末尾的「最近热门」，就是按近 30 天每篇文章的访客数（两条线加起来）排出来的前几篇。页面上只显示先后顺序，不显示人数；这个排名公开在 `/hot.json`，里面也只有文章名的顺序。

## 留言板

在[留言板](/guestbook/)贴便签时，服务器会存：

- 你填的内容、署名（可不填）、便签颜色、所在页面的语言、提交时间；
- Cloudflare 根据 IP 查出的国家、省份和城市，**只在我审核时看**，不公开；
- 一个当天有效的 IP 哈希（同样加了每天更换、次日删除的盐），只用来限制同一个人短时间内连发。

留言要我看过才公开，公开的只有署名、内容和日期。想删掉自己的留言，用下面的联系方式告诉我。你自己还没审核的便签，会在你的浏览器里留一份副本（localStorage，键名 `zq-guestbook-mine`），只有你能看到，审核通过后自动清掉。

## 只存在你浏览器里的数据

- **深色 / 浅色模式**：如果你手动切换过，选择会存在浏览器的 localStorage（键名 `zq-theme`），只在你的设备上，不会发给任何服务器。
- **站内搜索**：搜索索引从本站下载，匹配在你的浏览器里完成，本站没有搜索服务器。
- **自己的待审留言**：见上面「留言板」一节（键名 `zq-guestbook-mine`）。

## 托管与 CDN

网站通过以下服务托管和加速：

- **Cloudflare Pages**（海外读者）：可能记录访问日志用于安全防护；Cloudflare 可能设置必要的安全 Cookie（如 `__cf_bm`）
- **阿里云 OSS + CDN**（国内读者）：可能记录访问日志

这些日志由平台自动生成。本站只做一件事：每天读一次阿里云 CDN 的日志，数出各家爬虫的访问次数、各地的真人浏览数和每篇文章的浏览数（见「本站自己的计数」），其余内容不保存。字体、图片和脚本都从本站自己的域名加载（Cloudflare Web Analytics 的脚本除外），不经过其它字体或图片 CDN。
