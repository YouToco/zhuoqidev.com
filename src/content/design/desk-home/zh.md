## 看点

- **拖着会歪**：按住卡片拖动时，脚本按横向速度算一个 `--tilt`，CSS 里 `.pin.dragging { rotate: calc(var(--tilt) * 1deg); scale: 1.035 }`。松手删掉 `--tilt`，`rotate` 的过渡用 `linear()` 写的弹簧曲线，卡片会晃一下再摆正。
- **位置记在本机**：松手时把位置存进 `localStorage`，横向存「占桌面宽度的比例」、纵向存像素，窗口变宽变窄都还在桌面里。「整理桌面」一键清掉。
- **桌面图标**：鼠标单击是选中（名字变蓝底），双击才打开；键盘回车和手指轻点直接打开，和真桌面一样。
- **小窗口**：拖标题栏移动、拖右下角改大小，红黄绿三个灯是关闭 / 收起 / 放大，双击标题栏也能放大，Esc 关闭。收起和放大用弹簧曲线过渡，拖动则是跟手的，不加过渡。
- **星星**：桌面空白处有一圈淡淡的星星在闪，鼠标靠近会被「推开」；点空白处会冒出一颗小星星。
- **窄屏**：720px 以下所有卡片排成一列，不能拖，装饰元素收起来。

## 怎么用

1. 桌面容器 `position: relative`，每张卡片加 `class="pin"`，想让它能拖再加 `data-drag` 和一个唯一 `id`（存位置用）。
2. 每张卡片的初始位置写在 CSS 里，`left` 用 `min(70%, calc(100% - 卡片宽))` 这种写法，窄一点的屏幕也不会出界。
3. 把脚本里「draggable cards」和「stars」两段拷过去，改一下 `KEY`（存储用的键名）。
4. 要开窗口的图标写成普通链接 `<a class="desk-icon" href="/about/" data-win="...">`。示例里窗口内容来自 `<template>`；真实网站可以换成 `<iframe src="链接">`，让窗口里显示站内页面。
5. 窄屏的断点（示例是 720px）要和你的布局一致：断点以下不拖动，卡片按源码顺序排一列。

## 坑

- 卡片本身带 `transform: rotate(...)` 时，拖动倾斜要用独立的 `rotate` 属性，两者会叠加；都写在 `transform` 里会互相覆盖。
- 卡片上要 `touch-action: none`，不然手指拖卡片时页面会跟着滚。但窄屏的单列布局要改回 `auto`，否则手指放在卡片上滑不动页面。
- 拖动开始前留 4px 的死区，不然点一下卡片里的链接也会被当成拖动并写一次存储。
- `localStorage` 在隐私模式、禁用站点数据时会抛错，读写都要包 `try/catch`。
- 窗口里如果放 `iframe`，拖动或缩放窗口时 `iframe` 会吞掉指针事件，要在拖动期间给它 `pointer-events: none`。
