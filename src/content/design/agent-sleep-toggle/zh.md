在 recent.design 看到 Michael Filipiuk 的一段 7.7 秒录屏（只有视频），我和 Agent 把关键几帧（睡着前后各 0.6 秒、每 40ms 一帧）抽出来，对着原片一帧一帧调出来的复现。

## 看点

- **一条路径在六边形和圆之间变形**：六边形和圆都写成「每个角度一个半径」，各取 120 个点，任意比例混合都是一个合法形状，所以能平滑地从六边形捏成圆，中间那帧是一个蓝灰色的圆角团子，和原片一样。
- **圆角六边形用 p-范数**：六边形 = 六个面法向 `x·nᵢ ≤ a`；把「取最大」换成 p-范数（`P = 16`），角就圆了、边还是直的。`P` 越小越圆，太小边会鼓出来。
- **睡着是三件事一起发生**（0.19 秒）：形状变圆并缩小（半径约为六边形的 0.76）、颜色从亮蓝经灰蓝变成灰、眼睛从竖着的胶囊变成小圆点再变成两道短线（分两段插值，中间帧才是「点」），两道线还一高一低、各歪一点，看起来是犯困。
- **缩下去还会回弹，睡着还在呼吸**（逐帧量原片的宽度得出）：收缩时先冲过头到最终大小的 95%（0.19 秒），再慢慢鼓回 101%（0.45 秒），0.6 秒落定；睡着以后约 4.4 秒一呼一吸，在 100% 和 95% 之间缓慢起伏。不是「啪」一下缩成定死的大小，所以看着是活的。
- **醒来带弹簧**：0.13 秒变回六边形，0.19 秒冲到 103%，0.4 秒落定；从呼吸到一半的大小直接接上，不会跳。两段都写成关键帧（时间、缩放），段与段之间用 smoothstep 连接。
- **头顶的 z**：三个粗体 z 轮流从头的右上方往右上飘、变大、淡出（CSS 动画，相差 1/3 周期）。
- **醒着会看你，而且是「转头」不是「歪头」**：眼睛跟着鼠标走，往侧边看时胶囊基本保持竖直、整体平移过去；**靠那一侧的眼睛变小约 13%、变窄约 18%**，另一只略大一点，两眼间距收 18%，看起来是脸转了过去（近侧的眼睛转到了侧面）。静止时只有约 6° 的倾斜；快速扫过去时眼睛会按移动速度往反方向「甩」一下再回正（最多 22°）。往下看的位移比往上大，因为眼睛平时就偏上。每 2.6–5.2 秒眨一次眼。

## 怎么用

1. 拷 `.agent`、`.mascot`、`.zs`、`.state` / `.switch` 的 CSS 和整段脚本。
2. 形状参数在脚本顶部：`A`（六边形高的一半）、`R`（睡着的圆半径）、`P`（圆角）；颜色在 `SKIN()`，浅色、深色各一套。
3. 开关是真的 `role="switch"` 按钮，外面包一层 `<label>`，点「Active」字样也能切换；状态变化写进 `aria-live` 区域，读屏会念「已停用，正在睡觉」。

## 坑

- `<label>` 里放按钮时，别再给 label 加一个「点了就 `button.click()`」的监听：label 自己就会转发点击，会切换两次。
- 渐变放在会变形的路径上，用默认的 `objectBoundingBox` 坐标（`y1=0 y2=1`），渐变跟着形状的外框走；写成 -1…1 会只露出中间一段颜色。
- 每帧重算 120 个点的路径很便宜，但别在一页上放几十个；看不见时可以停掉 `requestAnimationFrame`。
- 眼睛跟随只在 `pointermove` 时更新目标，真正的位置每帧往目标靠 16%，这样鼠标抖动也不会让眼睛跳。`prefers-reduced-motion` 下不跟随、不眨眼、形状直接切换，z 静止。
