## 看点

- **一张纸的底**：奶油色 `--paper` 加 22px 一格的点阵（一个 `radial-gradient` 就够），卡片比纸再白一点，像纸上贴了张卡。
- **三支笔**：钢笔蓝（链接、主按钮、虚线边框）、印章红（编号、批注、印章）、荧光黄（重点、标题下划线、便利贴）。三种颜色各管一件事，页面就不乱。
- **四种声音**：标题用粗宋体，正文用系统无衬线（行高 1.9），标签 / 日期用等宽，手写体只出现在大标题和批注上，正文始终好读。
- **荧光笔是真的荧光笔**：短词用「下半截渐变」的 `.mark`；长标题用 `text-decoration` 加粗下划线再往上提（`text-underline-offset: -.2em`），换行也跟着走。
- **纸上小物件**：歪 3 度的便利贴、半透明条纹胶带、竖排文字的方印、内圈留白的圆章、歪着的圆章当提示框图标。
- **深色是夜里的书桌**：底色、墨色、三支笔都有一套夜间值（演示里两套色板并排）；便利贴、终端这类「实物」基本保持原色。顶栏的按钮可以手动切换，选择记在 `localStorage`。

## 怎么用

1. 拷 `:root` 的变量和 `:root[data-theme="dark"]`、`@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) … }` 两段夜间值。
2. `body` 背景直接拷那行点阵；需要的部件按类名拷：`.card` / `.tape` / `.sticky` / `.seal` / `.stamp-round` / `.chip-btn` / `.tag` / `.mark` / `.callout`。
3. 要手动切换：`<head>` 里放演示开头那段内联脚本（首帧前恢复主题，不闪），按钮脚本拷底部那段。
4. 字体按自己的站点换：演示只用系统字体，手写体落到楷体。想要更像手写，就自己挑一款开源手写字体。

## 坑

- 夜间值要写两遍（手动选择一份、跟随系统一份），漏一处就会出现「系统是深色，手动切到浅色却还是深色」。
- `.t-h2::before` 这种块级伪元素会继承标题的 `text-decoration`，编号也被划上荧光笔；改成 `inline-block; width: 100%` 就不会。
- 荧光黄在深色背景上刺眼，夜间要换成暗金（`#7d6416`），重点用的半透明黄也要调低。
- 中文手写字体很大（几 MB），一定要按页面实际用到的字切子集；不切的话手机上的性能分会掉一大截。
- 便利贴、终端在两种模式下颜色不变，里面的文字颜色要写死，不能用会随主题变的 `--ink`。
