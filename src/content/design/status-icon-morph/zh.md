recent.design 上一段 3.3 秒的录屏（Apple 的设计，只有视频）：状态栏里的信号、Wi-Fi、电池三个图标合成一个带圈的 Wi-Fi。我和 Agent 用 ffmpeg 把 188 帧全抽出来，对每一帧做连通块分析，量出每个零件的位置，再把复现版按原片的取景渲染出来、和原片逐帧做像素差，一直调到平均差异和静止帧的抗锯齿底噪持平（约 5%，最差一帧 9%）。

## 看点

下面的时间都从「第一样东西开始动」算起（原片先静止约 1 秒），整段 2.3 秒。

- **电池先收「电池头」，再收身子**（0–0.53 秒）：右边那个小凸起先往左滑进电池里（0.07 秒就看不见了），然后电池左边不动、右边往左缩，像在被卷起来；圆角半径始终是 `min(66, 宽/2)`，所以缩到一半自然变成胶囊，最后成了一根 34px 粗、180px 长的竖线。
- **信号格像被一块天花板往下压**（0.07–0.70 秒）：最右那格先往下沉，顶边沿一条慢起、中间快、落地慢的曲线下降；左边每一格晚约 66ms 跟着同一条曲线走，**压到自己顶边时才开始动**，所以矮的格子起步更晚（0.07 / 0.20 / 0.33 / 0.47 秒），最后都停在 46px 的圆点上，底边一直不动。
- **那根线是一条「蛇」，沿一条路径爬**（0.63 秒起）：先竖直往下掉，在右下角拐一个 U 形弯（0.77 秒），再逆时针螺旋着往上收，0.97 秒在顶上并入最终那个圆（半径 216.5）。这一路它长度不变（146px），速度慢起、0.8 秒前后最快、并入圆时略减速。
- **并圈之后头尾分开走**（1.13–2.03 秒）：尾巴继续平滑减速，头却突然加速（1.27 秒前后最快，约是尾巴的 4 倍），于是弧线从 37° 一口气拉到 240°，0.5 秒拉到九成，之后慢慢停住。头从起点算一共绕了一圈半左右，最后弧的两端停在 120° 和 240°（时钟方向，12 点为 0°），缺口正对下方。
- **Wi-Fi 让位**（0.67–1.23 秒）：只平移和缩放，往右挪 33px、缩到 82%，正好落到最终那个圆的圆心。
- **四个点追进缺口**（1.07–2.23 秒）：从最右那个开始、每隔约 65ms 出发一个，沿圆外面一条大弧线（离圆心最远约 340px）绕到圆下方，落在 150°、170°、190°、210°（间隔 20°）；落地前会冲过头、往上多走约 25px（1.9 秒），再慢慢沉回原位。
- **圆在成形时比终态大一点**：线绕过来的那 0.3 秒里，圆的半径比终态大 1–5px，圆心也略低，1.4 秒才收回终态。没有这一点，叠在原片上会差出一道细边。

## 怎么用

1. 整个画面是一个 SVG，坐标就是原片的像素、原点在最终圆心，所以表里的数可以直接拿来用；页面用 `viewBox` 缩放。
2. 动画不是 CSS 关键帧，而是七张时间表（`BODY`、`NUB`、`BARS`、`WIFI`、`LINE`、`DOTS`、`RING`）加一条路径（`LOOP`），每张表一行一个时刻；`draw(t)` 在两行之间线性插值，算出整张图。要改快慢，乘时间就行；要倒放，让 `t` 往回走。
3. 那根线用「沿路径的弧长」表示：`LINE` 里只存尾和头在路径上的位置，`strokeAlong()` 每 6px 取一个点连成折线，配 `stroke-linecap: round`。路径前半段是量出来的折线，过了 20° 之后就是圆。
4. 页面上有慢放（¼×）和时间轴，可以一帧一帧看；`?t=1234` 停在某个时刻，方便和原片对照截图。

## 坑

- **录屏是 30fps、文件却是 57fps**：每张新画面要么出现两帧、要么出现一帧。按「第几帧」算时间，复现会比原片抢先半帧，叠图时线和点总在前面一截。要先找出画面真正变化的那些帧，按 33.3ms 一格重新标时间。
- **别用 `ease` 去凑**：每个零件的速度曲线都不一样（电池先快后慢、线先加速后减速、圆的头尾一个加速一个减速），用三次贝塞尔凑不出来，直接用逐帧量出来的表最准。
- **量中心线时别信点云的小抖动**：竖线往下掉那段，从像素量出的中心线有 ±5px 的抖动，照着画会在线身上折出一个台阶；这一段改成手画的平滑曲线（往右缓移 6px 再拐进 U 形弯）后反而更贴原片。
- **短弧别拿来拟合圆**：只有几十度的弧，最小二乘拟合会拟出一个小圆（把笔画粗细当成了弯曲）。弧不到半圈时用固定圆心的平均距离量半径，超过半圈再拟合圆心。
- **电池头要藏起来**：它滑进电池里之后电池还在缩，等电池缩得比它窄，它会从右边重新露出来；滑进去就别再画它。
- `prefers-reduced-motion` 下不播放，点一下直接跳到合成后（或拆开前）的样子。
