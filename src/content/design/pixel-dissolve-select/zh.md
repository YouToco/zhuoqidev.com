在 recent.design 看到一段 8 秒的录屏（作者只发了视频、没给代码），我和 Agent 逐帧看完后从零写了像素版；又觉得整块方块碎掉不够好看，加了两种：像 Mac 最小化窗口的「神灯」，和像波浪往上退的「退潮」。演示顶上可以切换，默认神灯。

## 看点

### 神灯（默认）

- **切成细条**：把菜单克隆成约 3px 高的一条条（每条是整块菜单的克隆，用 `clip-path: inset()` 只露出自己那一条），每帧只改每条的 `transform`。条越细，漏斗的边越顺，不会出现台阶。
- **两段动作叠在一起**：前 45% 时间两侧弯成漏斗（漏斗口在按钮里名字的正中间），从 12% 开始各条往上滑进漏斗；每一条的宽度 = 漏斗在它**当前高度**的宽度，所以越往上越窄、文字被挤扁，就是 Mac 的感觉。
- **漏斗形状**：宽度按到漏斗口的距离走 `smoothstep`，在菜单高度的 55% 处就恢复全宽，让菜单多「撑」一会儿，脖子短而有弧度。
- **收进名字里**：菜单是被吸进名字的，名字随即换掉：旧名往上滑走并模糊，新名从下面浮上来，先是选项的颜色，再慢慢变回墨色；按钮像 Dock 图标接住窗口一样鼓一下（`scale: 1.045`）。
- **打开 = 倒放**：同一个函数把时间反过来跑，菜单从名字里「倒」出来。

### 退潮

- **波浪线是 `clip-path: polygon()`**：菜单只露出波浪线以上的部分；波浪是两条方向相反、频率不同的正弦叠加，所以不是死板的规则波。振幅随进度 `sin(πp)` 先大后小，起点和终点都是平的。
- **浪花**：沿着波浪线画一条选项颜色的亮线、一段往下渐隐的水色，再加几个跟着浪尖跑、长大后「破掉」的泡泡（SVG 圆，描边变细并淡出）；整层 SVG 裁到菜单的圆角矩形里，水只在卡片上，不会漫到页面。
- **方向**：收起时浪从下往上把菜单冲走（先慢后快，像水被拉回去）；打开时浪从上往下退，露出菜单。

### 像素（原版复现）

- **收起 = 打开倒放**：打开时像素从按钮下沿往下「倒」，前沿是一个深 V 形，后面渐渐变成卡片底色、真菜单从上往下显出来；收起时同一段动画倒着放（换成新选项的颜色），菜单从下往上退回成像素、像帘子一样被收回按钮里，名字碎一下再拼好。
- **倒放要掐头**：打开的最后一段只是在菜单下方收尾，倒放时会变成点击后约 150ms 的停顿，所以倒放从 85% 处开始。
- **真 DOM + 像素遮罩**：菜单是真的 `<ul role="listbox">`，动画期间每帧在小 canvas 上按 5px 格子画哪些格子该露出来，转成 `mask-image: url(dataURL)`；格子顺序用 4×4 Bayer 矩阵加随机数，看起来是规则网点。

三种都是真 DOM 菜单上的效果：键盘、读屏、点击照常，动画只是叠在上面的一层。

## 怎么用

1. 拷 `<style>` 里 `.pick` 开头的规则和第一段 `<script>`（它挂出 `window.pixelPick`）。
2. `pixelPick.mount(元素, { value, label, effect: "genie" | "tide" | "pixel", onChange })` 建一个，`setItems([{ id }])` 填选项；之后可以随时 `picker.effect = "tide"` 换效果。颜色写在脚本顶部的 `VIBES` 表里。
3. 换名字的两种动画也能单独用：`pixelPick.rollText(元素, 新文字, 颜色)`（滑入）、`pixelPick.swapText(…)`（像素碎掉再拼好）。

## 坑

- 神灯是把菜单克隆几十份：菜单里有图片、视频或很长的列表时会重，这时把条加粗（`H / 3` 改成 `H / 6`）或换退潮。克隆出来的元素要删掉 `id`、加 `aria-hidden`，否则页面里会有重复 id、读屏会读两遍。
- 神灯的条要互相重叠半个像素（`inset` 两边各减 0.6px），不然缩放后条与条之间会露出细缝。
- `requestAnimationFrame` 在后台标签页、被隐藏的预览窗格里不跑，动画会挂在半路：页面 `hidden` 或 `prefers-reduced-motion` 时直接跳过动画。
- 动画进行中又点了一次：先 `restart()` 把旧动画停掉、清掉克隆 / SVG / canvas 和 `clip-path`，再开始新的，否则会留下残影。
