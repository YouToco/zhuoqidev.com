照 Onlines 官网的首屏重做。它的设计点在于：一家做网站的工作室，就把自己干活的那块设计画布原样搬上首页，访客一打开就看到「我们是这样一起做东西的」。演示没有用原站的代码和素材。

## 看点

- **一个词就是首屏**：白底加淡网格，正中一个超大的粗黑「一起做。」，外面套着设计工具里的选中框（四角小方块，左上角写图层名）。只有黑、白和一点蓝。
- **滚动把画布搭起来**：一个 `@property --p` 从 0 滚到 1，每件东西（窗口线框、笔记本、手机、工具图标、AI 开关、聊天气泡、照片）都从自己的方向滑进来、渐渐出现。整个首屏 `position: sticky`，停在原地等它们到齐。
- **挂着名字的光标**：设计、开发、客户、Agent 四个光标各走一条循环路线，光标下面挂着彩色名牌。画布上真正的颜色就来自这几个名牌。访客自己的鼠标也会带一个「你」。
- **一句话逐字变黑**：后面那句话拆成一个字一个 `span`，用 `animation-timeline: view()` 让它们随滚动从浅灰变黑。
- **像编辑器里选中一段字**：「爱互联网」四个字罩着半透明蓝底，两头各有一根竖线和一个小圆点，跟在编辑器里拖选文字一样。
- **钴蓝卡片**：三张服务卡是钴蓝径向渐变，上面盖一层 SVG 噪点，有一点印刷感。

## 怎么用

1. 拷 `.canvas` 的网格背景、`.word` 和 `.sel` 选中框，把那个词换成你的。
2. 每件画布上的东西写成 `.piece`，用 `--x` / `--y` 定落点、`--ox` / `--oy` 定从哪滑进来、`--d` 让它晚一点出现。
3. 光标写 `.cur` 加一条 `@keyframes` 路线，名牌颜色给 `--c`。

## 坑

- 滚动驱动要配 `@property --p` 注册成 `<number>`，否则 `--p` 没法插值，东西会一下跳到位。不支持 `animation-timeline` 的浏览器里 `--p` 默认是 1，直接显示搭好的画布。
- 光标路线的 `left` 用 `cqi`（画布宽度）、`top` 用百分比。不能用 `translate` 的百分比，那是相对光标自己的大小。
- 画布上的东西多，手机上只留五六件（`.hide-s`），不然会把大字盖住。
- 不要放真实产品的 logo（Figma、VS Code 之类），用自己画的通用图标。
