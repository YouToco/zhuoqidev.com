## 看点

- **手绘风**：线条每笔画两遍、有一点抖，色块用斜线「涂」出来，配楷体一类的手写字体，比正规流程图亲切得多。
- **页面上只是图片**：图在构建时就画好了，正文里只放一张 `<img>`，不加载任何画图库，也不会出现「先闪一下代码再变成图」。
- **图纸不跟主题变**：深色模式下图依旧画在浅色纸上（`--sheet`），线条颜色不用为深色另配一套。
- **打开即适应窗口**：查看器打开时按图片宽高比算出「刚好放进窗口」的宽度（CSS 变量 `--r`），再用 `--s` 在 1–4 倍之间缩放。
- **缩放不跑偏**：滚轮、双指、双击都以光标（或两指中点）为中心放大，放大前后这一点在屏幕上不动，看细节不用再找位置。
- **操作齐全**：− / + 按钮、滚轮（触控板捏合也行）、双指、双击切换、键盘 `+ − 0` 和方向键；拖动平移；Esc 或点图外关闭，拖完松手那一下不会误关。

## 怎么用

1. 准备图：用 Mermaid 写图的文字源，构建时用无头浏览器加载 `@excalidraw/mermaid-to-excalidraw` 把它转成 Excalidraw 元素，再用 `@excalidraw/excalidraw` 的 `exportToSvg` 导出 SVG（导出的 SVG 自带手写字体，只含用到的字）。同时把场景存成 `.excalidraw` 文件，想手改就拖进 excalidraw.com 改完再导出。示例里的两张图是按同样风格预先画好的静态 SVG。
2. 文章里每张图写成 `<figure class="diagram"><img src="xxx.svg" width height alt></figure>`，`width` / `height` 写上图的原始尺寸，避免加载时页面跳动。
3. 拷贝 `dialog.zoom` 这段 HTML、相关 CSS 和脚本。脚本会自动把 `.diagram img` 包进按钮，点击就打开查看器。
4. 想让普通照片也能点开，把选择器改成你文章里图片的选择器即可；照片可以给查看器换一张更大的图片地址。

## 坑

- 打开前就要知道图片宽高比，不然大图还没加载完时没法算「适应窗口」的尺寸；SVG 写上 `width` / `height` 属性就有 `naturalWidth`。
- 舞台要 `touch-action: none`，否则手机上双指会缩放整个页面而不是这张图。
- 拖动结束时浏览器还会补发一次 `click`，要记下松手时间，300ms 内的背景点击不关闭查看器。
- Mermaid 转 Excalidraw 时，量文字宽度前必须先把手写字体加载好，否则框按后备字体算宽，字会撑出框外。
- 中文子图名会让转换器找不到子图，转换前先把非 ASCII 的子图 id 换成英文。
